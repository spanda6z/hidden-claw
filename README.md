# HIDDEN CLAW

Follow the money behind the token.

One-time access fee: **3 SOL**.

## Setup

1. Open `app.js`
2. Replace `YOUR_TREASURY_WALLET_ADDRESS_HERE` with your Solana wallet address
3. Deploy the static site (GitHub Pages, Vercel, Netlify, etc.)

## Payment

Users connect Phantom (or compatible) wallet and transfer exactly 3 SOL to the treasury.
Access is unlocked for that wallet (stored in localStorage for the demo).

How HIDDEN CLAW works.

Each specialist examines one part of a token. Together, they reveal the connections.

What happens in a scan

  1. Snapshot — The token is read at one point in time. The report records the block and time so every balance belongs to the same moment.
  2. Holder map — Every holder the data provider returns goes on the map with its balance and share of the supply.
  3. Wallets investigated in depth — A smaller set of wallets has its funding and trades traced. The report names the set and says why those wallets were chosen.
  4. Specialist review — Specialists each read their own part of the evidence and write findings that cite the records they rely on.
  5. Challenge — Each finding is challenged with the ordinary explanation that fits the same records. Findings can be qualified, weakened or rejected.
  6. The report — What survived is written up. Unresolved disagreements stay visible. What was not covered is listed.

The roles

Holder Analyst
Reviews the holder map and concentration.
Funding Tracer
Follows where holder funds came from.
Liquidity Checker
Determines whether liquidity can be pulled.
Trading Historian
Decodes trades and timing patterns.
Connection Scorer
Scores explainable relationship signals between wallets.
Skeptic
Challenges every finding with the ordinary explanation.
